# Kaspi Sim — Android APK

Симулятор Kaspi Bank для Android.

## Сборка APK через GitHub (без компьютера)

1. Создай аккаунт на [GitHub.com](https://github.com) (если нет)
2. Нажми **New repository** → назови например `KaspiSim`
3. Загрузи **все файлы** из этой папки в репозиторий
   (можно через сайт: Add file → Upload files)
4. Зайди во вкладку **Actions**
5. Выбери workflow **Build APK** → **Run workflow**
6. Подожди 3–6 минут
7. Когда сборка станет зелёной — открой её → скачай артефакт **KaspiSim-APK**
8. Внутри будет `app-debug.apk` — установи на телефон

### Важно
- Репозиторий может быть приватным
- Первый раз GitHub будет скачивать Android SDK — это нормально
- APK будет debug-подписан (для себя этого достаточно)
